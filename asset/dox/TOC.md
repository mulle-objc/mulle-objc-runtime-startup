# mulle-objc-runtime-startup Library Documentation for AI
<!-- Keywords: startup, initialization -->

## 1. Introduction & Purpose

**mulle-objc-runtime-startup** is a minimal startup library that provides the required initialization code for executables linking against mulle-objc-runtime directly (without higher-level frameworks).

**Key Features:**
- Provides `__register_mulle_objc_universe()` function for runtime initialization
- Minimal dependency footprint (only mulle-objc-runtime, mulle-atinit, mulle-atexit)
- Deterministic initialization and cleanup
- Static library linking at build time
- Enables standalone Objective-C executables without Foundation frameworks

**When to Use:**
- Creating pure mulle-objc-runtime executables without MulleObjC or MulleFoundation
- Minimal embedded systems where only runtime is needed
- Custom startup code that needs fine-grained control

**When NOT to Use:**
- Most projects should use MulleObjC-startup or Foundation-startup instead
- These provide richer functionality and are the recommended choice

## 2. Key Concepts & Design Philosophy

- **Minimal Startup**: Single function to initialize universe
- **Deterministic Ordering**: Uses mulle-atinit and mulle-atexit for controlled initialization
- **Universe Concept**: mulle-objc organizes classes into "universes" for isolation
- **Static Linking**: Compiled into executables; no shared library dependency
- **Lazy Initialization**: Universe created only when first accessed

## 3. Core API & Data Structures

### 3.1 Universe Initialization

#### `__register_mulle_objc_universe()`

**Function Signature:**
```c
struct _mulle_objc_universe *
   __register_mulle_objc_universe(
      mulle_objc_universeid_t universeid,
      char *universename
   );
```

**Purpose**: Initialize or retrieve the Objective-C universe for the current executable.

**Parameters:**
- `universeid` (uint32_t): Unique identifier for this universe (usually generated by compiler)
- `universename` (char *): Human-readable name for debugging (e.g., "main universe")

**Returns:**
- Pointer to initialized `struct _mulle_objc_universe`
- Same universe instance for same thread/process
- Universe is initialized if not already present

**Behavior:**
1. Looks up existing universe by `universeid`
2. If not found, retrieves/creates universe via `__mulle_objc_global_get_universe()`
3. If universe is uninitialized, calls `_mulle_objc_universe_bang()` to initialize
4. Returns initialized universe pointer

**Key Detail**: This function is idempotent—calling it multiple times returns the same universe.

### 3.2 Universe Concepts

#### Universe Structure (from mulle-objc-runtime)

**Conceptual Definition** (Objective-C runtime):
```c
struct _mulle_objc_universe {
   // Internal runtime state:
   mulle_objc_universeid_t id;           // Unique ID
   char *name;                           // Debug name
   // Class/method metadata
   // Caches for fast dispatch
   // Memory allocator reference
   // etc.
};
```

**Purpose**: Encapsulates all Objective-C runtime state:
- Class hierarchy and metadata
- Method lookup caches
- Instance tracking (for debug)
- Memory management context

#### Universe ID

- **Type**: `uint32_t` (unsigned 32-bit integer)
- **Typical Value**: Computed from source files by compiler
- **Uniqueness**: Different ID per universe (allows multiple isolated universes in one process)
- **Example**: `0x42445344` (hex) for main universe

#### Universe Name

- **Type**: `char *` (C string)
- **Purpose**: Human-readable identifier for debugging
- **Example**: `"main universe"` or `"plugin_universe"`
- **Lifetime**: Must remain valid for program duration

### 3.3 Related Functions (from dependencies)

These are NOT provided by mulle-objc-runtime-startup but referenced:

#### `__mulle_objc_global_get_universe()`

**Source**: mulle-objc-runtime

**Purpose**: Retrieve or create universe for given ID

#### `_mulle_objc_universe_bang()`

**Source**: mulle-objc-runtime

**Purpose**: Initialize universe if not already initialized

## 4. Performance Characteristics

- **Initialization**: O(1) once per universe; zero cost after first call
- **Memory**: Single universe structure (~4 KB) per process/universe
- **Call Overhead**: Minimal—single function call, internal cache lookup
- **Thread-Safety**: Each thread/process has own universe (thread-local or process-local)

## 5. AI Usage Recommendations & Patterns

### Best Practices

- **Call Once**: Invoke `__register_mulle_objc_universe()` once at program startup (before creating objects)
- **Main Thread**: Call from main thread before spawning worker threads
- **Fixed IDs**: Use consistent `universeid` for reproducible behavior
- **Error Handling**: Universe initialization should not fail in normal operation; abort if NULL returned

### Common Pitfalls

- **Missing Call**: Not calling `__register_mulle_objc_universe()` causes uninitialized universe crash
- **Invalid ID**: Using 0 as universeid is valid but uncommon; most projects use non-zero
- **Multiple Calls**: Multiple calls with different IDs create separate universes (rare use case)
- **Memory Leak**: If `universename` is dynamically allocated, ensure it persists (or is statically allocated)

### Idiomatic Usage

**Pattern 1: Basic Executable Startup**
```c
#include <mulle-objc-runtime/mulle-objc-runtime.h>

int main(int argc, char *argv[]) {
    // Initialize runtime universe
    struct _mulle_objc_universe *universe = 
        __register_mulle_objc_universe(0x12345678, "main");
    
    if (!universe) {
        fprintf(stderr, "Failed to initialize universe\n");
        return 1;
    }
    
    // Now Objective-C code can run
    id obj = [[MyClass alloc] init];
    // ...
    return 0;
}
```

**Pattern 2: With Objective-C Generated Startup**
```c
// mulle-clang generates initialization functions like:
MULLE_C_NO_INLINE
extern struct _mulle_objc_universe  *
   _mulle_objc_init_universe( void);

int main(int argc, char *argv[]) {
    // Generated function calls __register_mulle_objc_universe internally
    struct _mulle_objc_universe *universe = _mulle_objc_init_universe();
    if (!universe) {
        return 1;
    }
    
    // Objective-C code here
    return 0;
}
```

## 6. Integration Examples

### Example 1: Minimal mulle-objc Executable

```c
#include <mulle-objc-runtime/mulle-objc-runtime.h>
#include <stdio.h>

// Objective-C runtime startup linkage
extern struct _mulle_objc_universe *
   __register_mulle_objc_universe(mulle_objc_universeid_t id, char *name);

int main(int argc, char *argv[]) {
    // Initialize mulle-objc runtime
    struct _mulle_objc_universe *universe =
        __register_mulle_objc_universe(0xDEADBEEF, "minimal");
    
    if (!universe) {
        fprintf(stderr, "Failed to initialize mulle-objc universe\n");
        return 1;
    }
    
    printf("Universe initialized: %p\n", (void *)universe);
    return 0;
}
```

**Linking:**
```bash
mulle-clang -o myapp main.c
# Requires linking: mulle-objc-runtime-startup, mulle-objc-runtime, mulle-core
```

### Example 2: Compiler-Generated vs Manual Initialization

```c
// WITHOUT mulle-objc-runtime-startup:
// Must manually call __register_mulle_objc_universe()

// WITH mulle-objc-runtime-startup (recommended):
// Compiler-generated code calls it automatically via mulle-atinit

// Application code (same either way):
#import "MyClass.h"

int main() {
    id obj = [[MyClass alloc] init];
    // Universe is already initialized by startup code
    return 0;
}
```

### Example 3: Multiple Universes (Advanced)

```c
#include <mulle-objc-runtime/mulle-objc-runtime.h>

int main() {
    // Initialize primary universe
    struct _mulle_objc_universe *main_universe =
        __register_mulle_objc_universe(0x11111111, "main");
    
    // Initialize plugin universe (separate namespace)
    struct _mulle_objc_universe *plugin_universe =
        __register_mulle_objc_universe(0x22222222, "plugin");
    
    // Classes can be defined in each universe independently
    // Message dispatch remains separate per universe
    
    return 0;
}
```

### Example 4: Startup with Error Checking

```c
#include <mulle-objc-runtime/mulle-objc-runtime.h>
#include <stdlib.h>

static struct _mulle_objc_universe *
init_universe(mulle_objc_universeid_t id, const char *name) {
    struct _mulle_objc_universe *universe =
        __register_mulle_objc_universe(id, (char *)name);
    
    if (!universe) {
        fprintf(stderr, "FATAL: Could not initialize universe '%s'\n", name);
        exit(EXIT_FAILURE);
    }
    
    return universe;
}

int main() {
    struct _mulle_objc_universe *u = init_universe(0x42, "app");
    printf("Running with universe %p\n", (void *)u);
    return 0;
}
```

## 7. Dependencies

- **mulle-objc-runtime** - Core runtime engine; provides universe structures and initialization
- **mulle-atinit** - Deterministic initialization ordering
- **mulle-atexit** - Deterministic cleanup and shutdown

**No Standard Library Requirements** - All dependencies are pure mulle-sde components
